# Anlise-Economia
Este projeto é uma análise exploratória de dados feita em Python, utilizando a biblioteca Pandas para manipulação e organização das informações.
O que foi feito:
Importação e tratamento dos dados
Manipulação de colunas
Criação de estatísticas descritivas
Organização dos dados em tabelas mais claras
Tecnologias utilizadas:
- Python
- Pandas
- Google Colab
Objetivo
O objetivo deste projeto é praticar análise de dados em Python de forma simples, entendendo como manipular e transformar informações para gerar insights iniciais.
